FsLightbox Demo

A vanilla JavaScript lightbox — no jQuery, no dependencies

1. Basic Image Gallery

Add data-fslightbox="gallery1" to any <a> tag. All links sharing the same value become one navigable gallery. 

<!-- All links with the same data-fslightbox value form ONE gallery -->
<a data-fslightbox="gallery1" href="image-full.jpg">
  <img src="thumb.jpg">
</a>

2. Mixed Media Gallery

FsLightbox auto-detects the source type from the URL. Images, YouTube links, and HTML5 video all work in the same gallery.

Image
YouTube video
Image
HTML5 video
 
<!-- FsLightbox recognises the URL pattern automatically -->
<a data-fslightbox="gallery2" href="photo.jpg">...</a>
<a data-fslightbox="gallery2" href="https://youtube.com/watch?v=...">...</a>
<a data-fslightbox="gallery2" href="video.mp4">...</a>

3. Captions

Use the data-caption attribute — HTML is fully supported for rich formatting. 

<a
  data-fslightbox="gallery3"
  data-caption="<h2>Title</h2><p>Description</p>"
  href="image.jpg">
  <img src="thumb.jpg">
</a>

4. Multiple Independent Galleries

Different data-fslightbox values create separate, isolated galleries. Each gallery below only cycles through its own images.

Gallery A — Nature

Gallery B — Architecture

<!-- Gallery A -->
<a data-fslightbox="gallery-a" href="nature1.jpg">...</a>
<a data-fslightbox="gallery-a" href="nature2.jpg">...</a>

<!-- Gallery B -- entirely separate -->
<a data-fslightbox="gallery-b" href="arch1.jpg">...</a>

5. Inline Text Triggers

Links don't need thumbnails. Any <a> tag with data-fslightbox works — even plain text.

View a landscape | View another landscape | View a third landscape 
<!-- Plain text links work fine -- no <img> needed -->
<a data-fslightbox="gallery" href="photo.jpg">Click to view</a>

6. Dynamic Source Addition

After adding new <a> tags to the DOM, call refreshFsLightbox() so the lightbox picks them up.

Static slide
 
// After dynamically inserting <a> tags...
refreshFsLightbox();  // let fslightbox re-scan the DOM

7. Custom Attributes

Any data-* attribute (except data-fslightbox and data-caption) is passed through to the rendered source element. data-alt becomes the alt attribute on the <img> inside the lightbox. 

<!-- data-alt is passed to the full-size <img> in the lightbox -->
<a data-fslightbox="gallery4"
   data-alt="Detailed description — becomes alt text on the full image"
   href="full-image.jpg">
  <img src="thumb.jpg">
</a>
