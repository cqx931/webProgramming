Exercise: Populate Data from JSON & Filtering

Render DOM elements from JSON data and filter them by tag — all in vanilla JavaScript.

Part A — Fetch data & render cards
  1. Data is preloaded for you from data.json
  2. Loop over the result and create one <div class="card"> per item.
  3. Insert them into #card-container.
Part B — Filter by tag
Add click listeners to the filter buttons. When a button is clicked, show only cards whose .tags array includes that tag. Clicking "All" shows everything. Highlight the active filter button.
