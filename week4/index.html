1. More Pseudo Selectors

In Week 2 we have seen how to use CSS pseudo selectors to target specific elements(first child, nth child...) on the page. Pseudo-classes also allow you to style elements based on their state or user interactions. This is very powerful for creating basic interactive effects without needing JavaScript. CSS can respond to user actions with pseudo-classes and control how elements can be displayed differently, shown or hidden.

:hover

The most commonly used pseudo-class for interactivity is :hover, which applies styles when the user hovers their mouse over an element. This is often used to create visual feedback for buttons, links, and other interactive elements.


#hover-btn:hover   { 
    background: #fac901;  
    color: black;
}    /* mouse over -> yellow */

:active and :focus

In addition to :hover, there are other pseudo-classes that can be used to create interactive effects.

The :active pseudo-class applies styles when an element is being activated (e.g., when a button is being clicked), while the :focus pseudo-class applies styles when an element is in focus. More importantly, it will continue to stay in focus until the user activates another element. (e.g.when a user click somewhere else).

#active-btn:active  { background: #1c6ea4; }   /* while clicking */
/* Notice that the focus border only switch off when the user switch to another element */
#focus-btn:focus { outline: 2px solid red;} 
input:focus  { outline: 2px solid red; }

Combination of all three

You can also combine :hover, :active, and :focus pseudo-classes to create more complex interactions. For example, you can change the background color of a button when it is hovered over, clicked, or focused to provide clear visual feedback to users about the different states of the button.

#interact-btn:hover { background: #fac901; }   /* mouse over -> yellow */
#interact-btn:focus { outline: 2px solid black; } /* keyboard focus -> black outline */
#interact-btn:active { background: #1c6ea4; }   /* while clicking -> blue */

Notice that if you write sth like this, the rule is only triggered if a button is on :hover, :active, and :focus at the same time.

#bad-interact-btn:hover:active:focus { background: #1c6ea4; }

Oder of styles

Also the order of the pseudo-classes in your CSS can affect how styles are applied. For example, if you define styles for :hover after :active, the hover styles will take precedence over the active styles when both states are active at the same time. It's important to consider the order of your CSS rules to ensure that the desired styles are applied correctly.

/* The order of pseudo-classes matters */
/* :active is only applied when btn is clicked but not hovered*/
#oder-demo-btn:active { background: #1c6ea4; }   /* while clicking -> blue */
#oder-demo-btn:hover { background: #fac901; }   /* mouse over -> yellow */
#oder-demo-btn:focus { outline: 2px solid black; } /* keyboard focus -> black outline */

Mobile

On mobile devices, the :hover pseudo-class does not work as expected since there is no mouse cursor. Instead, you can use the :active pseudo-class to create interactive effects when users tap on elements. Additionally, you can use media queries to apply different styles for mobile devices to ensure a better user experience.

@media (hover: none) {
    .interact-btn:active {
        background: #2980b9; /* Apply hover styles on tap for mobile */
    }
}

Links: visited or not

There are also pseudo-classes that can be used to style links based on whether they have been visited or not. The :visited pseudo-class applies styles to links that the user has already visited, while the :link pseudo-class applies styles to links that have not been visited yet. This can be useful for providing visual feedback to users about which links they have already clicked on.

a:link { color: blue; }    /* unvisited link */
a:visited { color: purple; } /* visited link */

2. Cursor Styles

Another very helpful but subtle visual cue for interactivity is changing the mouse cursor when the user interacts with an element. The CSS cursor property changes the mouse cursor when hovering over an element. Move your cursor over the examples below to see how the cursor changes accordingly.

cursor: pointer; /* you can find other common values in the demo below */
pointer text grab help crosshair move not-allowed wait zoom-in zoom-out

It's important to use cursor styles appropriately to provide clear visual feedback to users about which elements are interactive and what kind of interaction they can expect. Some cursor changes are automatically applied by the browser for certain elements (e.g., pointer cursor for links or text cursor for input) , but you can also customize the cursor for other elements or change the default behavior to adjust to your design and user experience needs. And of course you can combine cursor styles with pseudo selectors to create more complex interactions and precise visual clues.

3. CSS Transitions

CSS transitions allow you to smoothly animate changes to CSS properties when they occur. By defining a transition on an element, you can specify which properties should animate and how long the animation should take.

Notice that we add the transition property to the default state of the element, and then specify the new styles in the other state (e.g., :hover). When the user interacts with the element, the transition will automatically animate the changes between the default and new styles, creating a smooth and visually appealing effect.

For more demo of different transition effects, you can check out this demo. 

.box {
    width: 100px;
    height: 100px;
    background: var(--mondrian-blue);
           /* property duration effect delay*/
    transition: background 0.5s ease 0.3s; /* animate background changes */
}
.box:hover {
    background: var(--mondrian-red); /* new background on hover */
}

Hover over the box to see the background color transition smoothly from blue to red.

Change Multiple Property Values

You can also specify multiple properties to transition by separating them with commas. This allows you to create more complex animations that involve changes to multiple CSS properties simultaneously.

.multi-transition-box {
    width: 100px;
    height: 100px;
    background: #225095;
    /* animate background and transform changes */
    transition: background 0.5s ease, transform 1s ease-in; 
}
.multi-transition-box:hover {
    background: #dd0100; /* new background on hover */
    transform: scale(0.5); /* scale down the box on hover */
}

Hover over the box to see both the background color transition and the scaling effect happen simultaneously, creating a more dynamic interaction.

4. CSS Transforms

CSS transforms allow you to apply various transformations to elements, such as scaling, rotating, skewing, and translating. These transformations can be used to create dynamic and interactive effects on your web page. For more demo of different transform effects, you can check out this demo. 

#box_transform {
    width: 100px;
    height: 100px;
}
#ox_transform:hover {
    transform: rotate(30deg) scale(1.5); /* rotate and scale the box on hover */
}

Hover over the box to see it rotate 30 degrees and scale up to 1.5 times its original size, creating a dynamic and interactive effect.

5.CSS Animation

If transition is not enough for what you have in mind, CSS animations allow you to create more complex animations by defining keyframes that specify the styles at various points during the animation sequence. You can control the duration, timing, and iteration count of the animation. For more demo of different animation effects, you can check out this demo. 

@keyframes bounce {
    0%, 100% { transform: translateY(0); }
    50% { transform: translateY(-20px); }
}
.bounce-box {
    width: 100px;
    height: 100px;
    background: gray;
    margin-top: 1rem;
    animation: bounce 1s infinite; /* apply the bounce animation */
}

The circle will continuously bounce up and down, creating a lively effect.

6. CSS Variables

We can also declare variables in css, which allows you to store values that can be reused throughout your CSS to achieve consistency. This makes it easier to maintain and update your styles, as you can change the value in one place and have it reflected everywhere the variable is used.

One of the most common use cases for CSS variables is to define a color scheme for a website. By declaring color variables at the root level, you can easily apply consistent colors across your entire site and quickly update the color scheme by changing the variable values. 


:root {
    --hover-color:#dd0100;
    --button-color:#fac901;
    --button-width: 200px;
}
.button {
    background: var(--button-color);
    color: white;
    padding: 0.7rem 1.2rem;
    border-radius: 4px;
    width: var(--button-width);
}
.button:hover {
    background: var(--hover-color);
}

The button uses CSS variables for its colors, making it easy to update the color scheme by changing the variable values.

7. CSS Functions

CSS functions allow you to perform calculations and manipulate values directly within your CSS. This can be useful for creating dynamic styles that adapt to different screen sizes or user interactions. You will often see CSS functions used in combination with other properties to create responsive designs, you will come across them as you explore code examples or websites from others. For a reference of different CSS functions, you can check out this css function reference list. 

.box {
    width: calc(20% - 40px); /* Calculate width based on parent container */
    background: hsl(200, 50%, 50%); /* Use HSL color function */
}
.box:hover {
    transform: translateX(10px); /* Translate in X Axis */
}

The box uses CSS functions to calculate its width, set its background color using HSL, and apply a rotation transform.

8. CSS Pseudo-Elements

CSS pseudo-elements allow you to style specific parts of an element or insert content before or after an element without needing additional HTML markup. This can be useful for adding decorative elements, icons, or additional information without cluttering your HTML.

::before, ::after

#emoji_button::before {
    content: "🔥"; /* Add a fire emoji before the button text */
    margin-right: 0.5rem;
}
#emoji_button:hover::after {
    content: "✨"; /* Add a sparkle emoji after the button text */
    margin-left: 0.3rem;
}

The button uses pseudo-elements to add decorative emojis before and after the button text, enhancing its visual appeal without additional HTML.

Sometimes you may also see pseudo-elements used to create custom shapes or effects, such as adding a decorative border, shadow or image. By using pseudo-elements creatively, you can enhance the design and functionality of your web page without needing to add extra HTML elements.

::first-letter

Another useful pseudo-element is ::first-letter, which allows you to style the first letter of an element. This can be used to create drop caps or add emphasis to the first letter of a paragraph.

p::first-letter {
    font-size: 4em; /* Make the first letter larger */
    color: #e74c3c; /* Change the color of the first letter */
    float: left; /* Float the first letter to the left */
    margin-right: 0.1em; /* Add some space after the first letter */
    font-family: 'Georgia', serif; /* Use a serif font for the first letter */
}
