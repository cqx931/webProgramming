Introduction to Javascript

In this section, we'll cover the basics of JavaScript syntax and how to use it to create simple interactions.

Basics

First let's try to open the browser console (press F12 or right-click and select "Inspect" then go to the "Console" tab) and type in some JavaScript code:

console.log("Hello, world!");

You should see "Hello, world!" printed in the console. This is the python print() equivalant and how we can use JavaScript to output information for debugging or interaction purposes.

// This is how to comment in single Line

Another important aspect of JavaScript is variables. We can declare variables using the var, let, or const keywords. For example: 
// Declare a variable called name, it's value can be changed later
let name = "Alice"; 
// Declare a constant variable called age, this value can't be changed later
const age = 30; 
// Note: var is the old way of declaring variables and is generally not recommended
var x = 10;

In this code, we declare a variable called name and assign it the value "Alice". We also declare a constant variable called age and assign it the value 30. The difference between let and const is that let allows you to reassign the variable later, while const does not allow reassignment.

var is the old way of declaring variables and is generally not recommended due to its global scope, which can lead to bugs. It's better to use let and const for block-scoped variables.

If you haven't learnt a programming language properly before, you can just ignore var, use let for variables that can change and const for variables that won't change.

DOM & Selectors

The Document Object Model(DOM) represents the structure of an HTML document as a tree of objects. It allows JavaScript to interact with and modify the content and elements of a webpage dynamically.

When an HTML document is loaded into a web browser, it becomes a document object. The document object is the root node of the HTML document. It contains all the elements of the webpage as child nodes. Each element in the HTML document is represented as an object in the DOM, and these objects can be accessed and manipulated using JavaScript. 

const title = document.title; // Get the title of the document
const url = document.URL; // Get the URL of the document
const body = document.body; // Get the body element of the document

In JavaScript, we can use selectors to access and manipulate elements on a webpage. 

// Selects the element with id
const element = document.getElementById("myElement"); 
// Selects all elements with the class "myClass"
const elements = document.getElementsByClassName("myClass"); 
// Selects all p elements
const all_p = document.getElementsByTagName("p");

The easist and most flexible way to select elements is by using the document.querySelector() method, which allows you to select elements using all possible CSS selectors. For example:

// Selects the first element that matches the CSS selector
const element = document.querySelector(".myClass p"); 
// Selects all elements with the class "myClass"
const elements = document.querySelectorAll(".myClass");

However, they are not as fast as other selector methods like getElementById() and getElementsByClassName(), so if what you want to select is possible to be done with the specific selectors, it's better to use that instead.

Dom Manipulation

JavaScript can manipulate the the DOM to change the content and style of a webpage.

For example, we can create a button that changes its text when clicked:

const button = document.getElementById("myButton");
button.addEventListener("click", function() {
    button.textContent = Date(); // We can change the HTML 
    button.style.backgroundColor = "orange"; // and the CSS
});

Event Listeners

Event listeners are a fundamental part of JavaScript interactivity. They allow you to respond to various user actions such as clicks, mouse movements, keyboard input, and more. By attaching event listeners to elements on your webpage, you can create dynamic and interactive experiences for users. Some common event listeners are:click, dbclick, mouseover, mouseout, keydown, keyup, submit, etc. 

document.addEventListener("keydown", function(event) {
    console.log("Key pressed: " + event.key);
});

In this example, we add an event listener to the entire document that listens for the "keydown" event. Whenever a key is pressed, the function will log the key that was pressed to the console.

Event listeners can also be added to any element on the webpage: 

<button id="myButton" onclick="console.log(this.id);">Click me</button>
