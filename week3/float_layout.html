Float Layout Demo

Simple 2-column layout using float.

Main content

This column is the main content area. It floats to the left and takes about two-thirds of the wrapper width. Notice I used percentage for width instead of fixed pixels. The content flows naturally and stays next to the sidebar until the container ends.

Why float?

Using float was a common layout technique before Flexbox and Grid. It is still useful for simple layouts or legacy support, but remember to clear floats so the parent container expands correctly.

Sidebar

This sidebar floats to the left as well, so it sits beside the main column. It uses a fixed width percentage and a small left margin for spacing.
