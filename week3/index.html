Week 3: CSS Layout

1. Positioning

CSS offers various positioning schemes to control how elements are placed on the page.

  • static: The default flow of the document.
  • relative: Positioned relative to its normal position.
  • absolute: Positioned relative to the nearest positioned ancestor.
  • fixed: Positioned relative to the viewport, stays in place during scrolling.
  • sticky: Toggles between relative and fixed based on scroll position.

position: relative

An element with position: relative; is positioned relative to its normal position in the document flow. Settings like the top, right, bottom and left properties will cause the element to be adjusted away from its normal position. These properties only work on positioned elements (elements with position set to relative, absolute, fixed, or sticky). 

/* Static: default flow */
.element {
    position: static;
    top:10px; /* has no effect */
    left:20px; /* has no effect */
}       
/* Relative: offset from normal position */
#relative {
    position: relative;
    top: 10px; /* moves down 10px */
    left: 20px; /* moves right 20px */
}

Relative

position: abolute

An element with position: abolute; is positioned relative to the nearest ancestor with a set position (any position other than static). However; if an absolute positioned element has no positioned ancestors, it uses the document body, and moves along with page scrolling.

Most of the time we use it together with position: relative; for the reference div in relation to an element by itself while keeping the parent element in the normal flow.

Absolute positioning removes the element from the normal document flow, so it does not affect the position of other elements. Notice that its parent is also not affected by it at all. 

/* Absolute: positioned relative to nearest positioned ancestor */
div.relative {
  position: relative;
  width: 400px;
  height: 200px; # if we remove the height from parent div, the parent doesn't adjust its height to the absolute child div 
  padding: 5px;
  border: 3px solid green;
}

div.absolute {
  position: absolute;
  top: 80px;
  right: 5px;
  width: 200px;
  height: 100px;
  padding: 5px;
  border: 3px solid red;
}

position: fixed

An element with position: fixed; is positioned relative to the viewport, which means it always stays in the same place even if the page is scrolled. Fixed positioning removes the element from the normal document flow, so it does not affect the position of other elements and other elements will not affect its position.

/* Fixed: positioned relative to the viewport */
div.fixed {
  position: fixed;
  background:#eee; 
  top: 200px;
  left: 10px;
  width: 150px;
  height: 50px;
  padding: 5px;
  border: 3px solid blue;
}
This div element as position: fixed

position: sticky

position: sticky; is relative new to positions (does not work for very old browsers) and it has a cute sticky effect. It behaves like relative until it reaches a defined scroll position, then it becomes fixed until it is out of the viewport. 

/* Sticky: toggles between relative and fixed based on scroll position */
div.sticky {
  position: sticky;
    top: 0; /* Sticks to the top of the viewport when you reach its scroll position */      
    background: #f39c12;
    padding: 5px;
    border: 3px solid orange;
}

2. Z-Index

Once we start to take elements out from the normal flow, there is a chance that they might overlap each other. The z-index property comes in handy when that happens. Elements with a higher z-index will appear in front of elements with a lower z-index.
If two positioned elements overlap without a z-index specified, the element positioned last in the HTML code will be shown on top. 

/* Z-Index: controls stacking order */
div.z-index-demo {
    position: absolute; /* z-index only works on positioned elements */
    z-index: 1; /* default value is auto */
    opacity: 0.8; /* for better visibility of overlapping elements */
    width:200px;
    height:150px;
    color:white;
    padding:5px;
    margin:40px;
    left:0;
    top:0;
}

div.z-index-demo.front { 
    z-index: 2; /* overrides z-index of 1 */
    left:40px;
    top:40px;
} /* appears in front */

div.z-index-demo.back { 
    z-index: 0; /*  overrides z-index of 1 */
    left:-40px;
    top:-40px;
} /* appears behind */
Red (z-index: 2)
Blue (z-index: 1)
Yellow (z-index: 0)

This is very useful when you want to put an image as a partial background of a div and put some text on top of it. You can set the image div to have a lower z-index than the text div, so the text will be visible on top of the image.

.image {
    position: absolute;
    z-index: 0;
    width: 100%;
    height: 100%;
    background-image: url('https://upload.wikimedia.org/wikipedia/commons/thumb/0/0a/Leuphana_Building.jpg/960px-Leuphana_Building.jpg');
    background-size: cover;
    background-position: center;
}       
.text {
    position: relative;
    z-index: 1;
    color: black;
    padding: 20px;
}

Z-index also takes negative values, which can be useful when you want to place an element behind the normal flow of the document(everything else). For example, you can use a negative z-index to create a background image that sits behind all other content on the page. However, be cautious when using negative z-index values, as they can make elements difficult to interact with.

If you want to create complicated layered effects or ensuring that certain elements always appear above or below others without needing to manage z-index values across the entire document, you can use the isolation property. We can set this property to isolate, which creates a new stacking context for the element and its children. 

/* Isolation: creates a new stacking context */
.isolated {
    isolation: isolate; # if we remove this line, the red div will disappear because it is behind the normal flow of the document
    position: relative; 
    background-color:#f0ede6;
}
#blue-div {
    position:absolute; 
    background-color:var(--mondrian-blue); 
}
#red-div {
    position:absolute; 
    background-color:var(--mondrian-red); 
    z-index:-1;
}

3. Float

The float property is used to wrap text around images or to create multi-column layouts. It can be a bit tricky to work with, especially when it comes to clearing floats and understanding how it interacts with the document flow.

/* Float: allows elements to float to the left or right */
img {
    float: left; /* or right */
    margin: 0 1rem 1rem 0; /* add some spacing */
}

4. Layouts

Normal layout flow

By default, elements are laid out in the normal flow of the document. Block-level elements stack vertically, while inline elements flow horizontally within their containing block. We can override this default behavior using CSS properties like display, position, float, and more to create various layouts.
-> Checkout the normal layout flow

Simple Float Layout

Once we have float, we can use it to create more complex layouts. For example, we can create a two-column layout with a sidebar and main content area by letting them float side by side. This is how websites were built before the introduction of more modern layout techniques like Flexbox and Grid. For more complex layouts, one usually uses a multi-column boilerplate that are based on floats.
-> Checkout the float layout

Flexbox Layout

CSS Flexbox is a one-dimensional layout system that allows you to arrange items either in rows or in columns. It is particularly useful for creating flexible and responsive layouts, as it can easily adjust the size and position of items based on the available space. -> Checkout the flexbox layout

A flexbox always consists of:

  • A Flex Container - The parent (container) element, where the display property is set to flex or inline-flex
  • One or more Flex Items - The direct children of the flex container automatically becomes flex items

Grid-based Layout

CSS Grid is a two-dimensional layout system that allows you to create complex, responsive grid-based layouts with ease. It enables you to control both rows and columns simultaneously. It is a very powerful layout system that takes a bit of time to learn. Due to the limited sessions of this class, we won't be able to cover that in details here. However, I highly recommend you to check it out after you are familiar with the flexbox system and other CSS concepts.

The classic problem: How to center a div?

Centering a div can be achieved using different CSS layout techniques depending on the context.

Margin Auto:

/* Centering with margin auto */
.centered {
    width: 200px; /* set a fixed width */
    margin: 0 auto; /* auto left and right margins */
    /* Vertical centering without using grid or flexbox is more complex and often requires additional techniques, such as using display: table or absolute positioning. */
}
Centered with Margin Auto

Flexbox:

/* Centering with Flexbox */
.container_flex {
    display: flex;
    justify-content: center; /* horizontal centering */
    align-items: center; /* vertical centering */
}
Centered with Flexbox

Grid:

/* Centering with Grid */
.container_grid {
    display: grid;
    place-items: center; /* centers both horizontally and vertically */
}

6. Background Images

The background property is a powerful shorthand that can set multiple background-related properties at once.

/* Shorthand for multiple background properties */
background: url('image.jpg') no-repeat center/cover;
background: linear-gradient(to right, #e74c3c, #3498db);
background: radial-gradient(circle, #2ecc71, #27ae60);

Background Images

The background-image property allows you to set an image as the background of an element. You can use the url() function to specify the path to the image. You can set the background image to cover the entire element, position it, and control whether it repeats or not using properties like background-size, background-position, and background-repeat. Detailed information about background properties can be found here. 

/* Set a background image */
div {
    background-color:rgba(255,255,255,0.8); /* Optional: add a semi-transparent overlay */
    background-image: url('https://upload.wikimedia.org/wikipedia/commons/thumb/0/0a/Leuphana_Building.jpg/960px-Leuphana_Building.jpg');
    background-size: cover; /* Make the image cover the entire element */
    background-position: center; /* Center the image */
    background-repeat: no-repeat; /* Prevent tiling */
}

div {

Gradient Backgrounds

CSS gradients allow you to create smooth transitions between two or more colors. 

/* Gradient Backgrounds */
div.linear-gradient {
    background: linear-gradient(to right, #e74c3c, #3498db); /* Linear gradient from red to blue */
}
div.radial-gradient {
    background: radial-gradient(circle, #2ecc71, #27ae60); /* Radial gradient from light green to dark green */

6. Media Queries

Media Queries

Media queries allow you to apply different styles based on the characteristics of the device or viewport. This is essential for creating responsive designs that adapt to various screen sizes and orientations. You can use it to change anything css can specify: layout, font size, colors, and other styles based on the screen size. 

/* Media Query Example */
@media (max-width: 600px) {
    .media-query-demo {
        background-color: lightblue;
    }
}

Resize the browser window to see the background color change to light blue when the viewport width is 600px or less.

Usually we will have media queries for mobile, tablet, and desktop views. The sizes for these views can vary, but a common practice is to use the following breakpoints:

  • Mobile: max-width: 600px
  • Tablet: min-width: 601px and max-width: 1024px
  • Desktop: min-width: 1025px
You can adjust these breakpoints based on your specific design needs and target audience.

Other than screen size, you can also use media queries to design how a website should look like when it is printed. You can use the @media print query to specify styles that will only apply when the page is printed. This allows you to create a print-friendly version of your website that hides unnecessary elements and optimizes the layout for paper.
