Flexbox Layout

Flexbox is a powerful CSS layout module that provides an efficient way to arrange items within a container, even when their size is unknown or dynamic. It allows for flexible and responsive designs without the need for floats or positioning.

1. Start the flex container

The display: flex; property turns a container into a flex container, enabling automatic flexbox layout for its direct children.

.container {
    display: flex;
    gap: 1rem;
}

2. Flex Direction

Flexbox operates in a 2 axes system: a main and a cross axis. The main axis is your defining direction of how your flex items are placed in the flex container. The flex-direction property defines the main axis along which flex items are arranged.

flex-direction: row (default)

Because the main axis changes with different flex-direction values, properties like justify-content and align-items will also behave differently. For example, justify-content: center; will center items horizontally in a row layout but vertically in a column layout.

7. Flex Property

The flex property is shorthand for flex-grow, flex-shrink, and flex-basis. It controls how items grow or shrink. You can specify very detailed responsive behavioiur with this value. Here we will first focus on static layout examples.

.item {
    flex: 1; /* shorthand for flex-grow: 1; flex-shrink: 1; flex-basis: auto; */
}

If you want to create two columns with a 2:1 ratio, you can set the first item to flex: 2; and the second item to flex: 1;. This will make the first item take up twice as much space as the second item within the flex container. 

.itemA {
    flex: 2; /* takes up twice as much space as item2 */
}
.itemB {
    flex: 1; /* takes up half the space of item1 */
}
Item A (flex: 2)
Item B (flex: 1)

If you have a fixed width item and you want the remaining space to be taken up by another item, you can set the fixed width item with flex: 0 0 200px; and the other item with flex: 1;. This will make the first item take up exactly 200px of space, while the second item will grow to fill the remaining space in the flex container. 

.itemA {
    flex: 0 0 200px; /* fixed width of 200px, no grow, no shrink */
}
.itemB {
    flex: 1; /* takes up remaining space */
}
Item A (flex: 0 0 200px)
Item B (flex: 1)

We can also combine the two examples above to create a three-column layout where the first column has a fixed width of 200px, the second column takes up twice as much space as the third column, and the third column takes up the remaining space. We can achieve this by setting the first item to flex: 0 0 200px;, the second item to flex: 2;, and the third item to flex: 1;. 

.itemA {
    flex: 0 0 200px; /* fixed width of 200px, no grow, no shrink */
}
/* item B+C will take up remaining space with the ratio of 2:1 */
.itemB {
    flex: 2; 
}
.itemC {
    flex: 1; 
}
Item A (flex: 0 0 200px)
Item B (flex: 1)
Item C (flex: 1)
